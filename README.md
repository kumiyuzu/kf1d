# kf1d

標準入力から受け取った1次元の時系列数値データ（赤外線距離センサや超音波センサの観測値など）に対し、1次元カルマンフィルタ（定常状態モデル）を適用してノイズを除去し、推定値を標準出力へ出力するコマンドです。

![test](https://github.com/kumiyuzu/kf1d/actions/workflows/test.yml/badge.svg)

## インストール方法

GitHubからリポジトリをクローンし、コマンドに実行権限を付与します。

```bash
$ git clone [https://github.com/kumiyuzu/kf1d.git](https://github.com/kumiyuzu/kf1d.git)
$cd kf1d$ chmod +x kf1d
```

## 使い方

標準入力から1行につき1つの数値を入力すると、逐次更新された状態推定値が1行ずつ標準出力に出力されます。

### 基本的な実行例

```bash
$ printf "10.5\n9.5\n10.2\n9.8\n" | ./kf1d
10.5
9.997512437810945
10.066122824907076
9.997297908282226
```

### オプション

コマンドラインオプションでノイズパラメータを変更できます。

* `-q` : プロセスノイズの分散 $Q$ を指定します（0以上の実数、デフォルト: `0.01`）。値を大きくすると観測値への追従性が高くなります。
* `-r` : 観測ノイズの分散 $R$ を指定します（0より大きい実数、デフォルト: `1.0`）。値を大きくすると平滑化（ノイズ除去）が強くなります。
* `-h` : ヘルプメッセージを表示します。

```bash
$ printf "10.0\n12.0\n" | ./kf1d -q 0.5 -r 0.5
10.0
11.333333333333334
```

### エラー時の挙動

以下の場合は標準エラー出力にエラーメッセージを表示し、終了コード `1` で終了します。

* 入力が空（0行）の場合
* 数値に変換できない文字列や空行が含まれている場合
* `-q` に負の値、または `-r` に `0` 以下の値が指定された場合

## テストの実行

付属のテストスクリプトで正常系および異常系の動作を確認できます。

```bash
$ ./test.bash
```

## 動作環境

* OS: Ubuntu 24.04
* Python: 3.12（標準ライブラリのみ使用）
